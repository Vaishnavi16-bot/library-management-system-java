# Library Management System

A simple console-based Library Management System developed using Java.

## Features

- Add book
- View book details
- Search book by ID
- Issue book to a student
- Return book
- Delete book
- Generate library report
- Menu-driven interface

## Concepts Used

- Java
- Object-Oriented Programming
- Classes and Objects
- Methods
- Scanner
- Loops
- Switch Case
- Conditional Statements
- Basic Data Handling

## How It Works

The application provides a menu through which users can manage library books.

Users can:
1. Add a book
2. View book details
3. Search for a book
4. Issue a book
5. Return a book
6. Delete a book
7. Generate a library report
8. Exit the application
